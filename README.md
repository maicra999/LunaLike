# 💬 LunaLike
A minimalistic cross-server chat and Japanese romaji transcriber for [Velocity](https://papermc.io/software/velocity/).  
[SignedVelocity](https://modrinth.com/plugin/signedvelocity) may be required for cancelling signed chat messages.

The implementation for the romaji transcription is based on [LunaChat](https://github.com/ucchyocean/LunaChat).
